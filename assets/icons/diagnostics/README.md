# Diagnostic icons

- Discord (white Clyde): [Discord Brand Assets](https://discord.com/branding).
- GitHub (white Invertocat): [GitHub Brand Toolkit](https://brand.github.com/foundations/logo).
- YouTube (red Play Button): vector geometry from [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/youtube.svg), displayed beside the service label and linked to YouTube. See [YouTube brand resources](https://brand.youtube/).
- Cloudflare: a generic network globe. The [Cloudflare trademark guidelines](https://www.cloudflare.com/trademark/) require written permission to use the logo in this context.

The brand marks identify the services tested. The launcher is an independent project.
